title: "What Ohio Law Actually Requires for Rental Smoke and CO Alarms"
summary: "Ohio rental properties must have working smoke alarms under the Ohio Fire Code, not the building code section many landlord articles cite, according to RL Property Management. Carbon monoxide alarms are required when a unit meets any of four separate triggers in fire code section 915, including a shared basement gas water heater, not just an in-unit gas appliance. Existing buildings faced a January 1, 2019 deadline to add CO alarms."
detail: "Most landlord content cites Ohio Revised Code 3781.104 for smoke alarm requirements, but that section only applies to apartment buildings and condominiums taller than 75 feet. The rules that reach a typical Franklin County duplex or small apartment building instead sit in the Ohio Fire Code, Ohio Administrative Code 1301:7-7-11, which requires single-station smoke alarms in existing rental occupancies and sets battery-backup and interconnection rules that change once a unit undergoes renovation. Carbon monoxide alarms are triggered by any one of four separate conditions in fire code section 915: a fuel-burning appliance or fireplace inside the unit, a fuel-burning forced-air furnace serving the unit, a fuel-burning appliance elsewhere in the building with a communicating opening, or an attached private garage. A unit with an all-electric kitchen can still require a CO alarm if a gas water heater sits in a shared basement with an opening into the unit's space. Existing buildings faced a January 1, 2019 deadline to add CO alarms under the fire code. Ohio Revised Code 5321.04 turns these code requirements into a landlord duty to keep the property in a fit and habitable condition, and the Ohio Supreme Court held in Sikora v. Wenzel that violating that duty counts as negligence per se, meaning a landlord who neither knew nor should have known about a failed alarm has a defense, but one who should have known does not. Columbus City Code adds its own layer: the owner installs detectors and must use hard-wired units in one to three family buildings built after April 26, 1978, while Columbus code assigns day-to-day operation and maintenance of the alarms to the occupant in buildings of that size."
why_it_matters: "A Columbus landlord relying on the commonly cited 75-foot building code section for a small duplex is citing the wrong law entirely, and could miss a CO alarm trigger, like a shared basement water heater, that the correct fire code section actually requires."
