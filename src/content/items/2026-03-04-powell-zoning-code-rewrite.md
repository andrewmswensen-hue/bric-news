title: "Powell Planning Department advances full zoning code rewrite"
summary: "The Powell Planning Department confirmed on March 4 that a complete rewrite of the city's zoning code is in progress, with public engagement sessions planned before any draft is presented to the Commission for first reading. The rewrite is expected to consolidate and modernize sections of the existing code that have been amended piecemeal over the last decade. A timeline for completion was not finalized. Planning staff encouraged property owners and investors to participate in scheduled public input opportunities."
why_it_matters: "Full zoning code rewrites come around once a decade or more, and the public-input window is when investor perspectives can actually shape the final document; if you own or underwrite in Powell, engaging early is meaningfully cheaper than trying to amend once the rewrite is locked in."
