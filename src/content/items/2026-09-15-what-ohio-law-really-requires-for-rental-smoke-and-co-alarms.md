title: "What Ohio law really requires for rental smoke and CO alarms"
summary: "A partner explainer from RL Property Management walks through which Ohio code actually governs smoke and carbon monoxide alarms in rentals. The commonly cited statute, ORC 3781.104, only applies to buildings over 75 feet tall; the rules that reach a typical Columbus duplex or single-family rental live in the Ohio Fire Code instead. Ohio Revised Code 5321.04 turns those code requirements into a landlord duty, and a violation can count as negligence per se under Ohio law."
detail: "Most landlord content on this topic points to the wrong law, according to the explainer. ORC 3781.104 governs apartment buildings and condominiums over 75 feet tall and took effect in 1981; it has nothing to do with a single-family rental in Westerville or a four-unit building in Clintonville. The rules that actually reach smaller rentals sit in the Ohio Fire Code, OAC 1301:7-7-11, which requires smoke alarms in existing rental units and carbon monoxide alarms when a unit meets any of four separate conditions, including a fuel-burning forced-air furnace or an attached private garage; existing buildings faced a January 1, 2019 deadline to add CO alarms. Ohio Revised Code 5321.04(A)(1) and (A)(2) convert those code requirements into a landlord duty to keep a rental in a fit and habitable condition, and a violation can be treated as negligence per se in an Ohio court. Columbus splits the duty further in its own code: the owner must install the detectors under Columbus City Code 4529.08, while the occupant of a one- to three-family dwelling is responsible for operating and maintaining them under CCC 4529.11. Battery-only alarms are allowed under the state fire code in existing buildings not undergoing construction, but Columbus separately requires hard-wired detectors in one- to three-family buildings built after April 26, 1978. The often-cited 10-year alarm replacement rule comes from NFPA 72 and manufacturer guidance, not from Ohio statute. This article is informational, reflects Ohio law and Columbus City Code as of September 2026, and is not legal advice."
why_it_matters: "Landlords who cite ORC 3781.104 in a lease or an inspection dispute are citing a law that does not apply to most Columbus rentals, and getting it wrong matters because a real violation of the correct fire code section can be treated as negligence per se, so it is worth confirming which code section, and which of Columbus's own installation and maintenance splits, actually apply to a specific property."
